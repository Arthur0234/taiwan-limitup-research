# Market Data Spec

## 目的
建立一份可重複使用的台股歷史資料，供 Entry、Stop、Winner Exit、Rotation 等研究共用，避免每個研究重新抓資料。

## 已決策

1. **資料範圍：2021–2026**
   - 先滿足目前研究，不先擴充更久歷史。

2. **不復刻舊研究資料**
   - 舊 cohort/count 不作為硬性驗收條件。
   - 理由：避免花時間考古，從新版正式資料重新建立研究基準。

3. **第一版使用原始股價**
   - 暫不處理除權息還原。
   - 理由：先降低資料建置複雜度；後續再獨立加入還原價版本。

4. **資料來源：TWSE + TPEx 官方資料**
   - 不使用 `prev_close × 1.1` 推算漲停價。

5. **儲存：Google Drive**
   - GitHub：保存抓取/整理程式、規格、測試。
   - Google Drive：保存產出的歷史資料檔。
   - 理由：大型資料檔不直接放 Git；目前也不需要額外維護主機。

6. **暫不每日自動更新**
   - 先建立固定研究資料集並完成策略研究。
   - 等策略需要日常選股時，再做每日更新。

## 第一版預期產物
- `prices.parquet`：個股每日開高低收、成交量等研究價格資料。
- `stock_info.parquet`：股票基本分類資料，用於排除 ETF／ETN／DR 等非普通股。

## 已實作

- `src/build_market_data.py` 直接抓 TWSE／TPEx 官方每日收盤資料。
- 原始回應依市場與日期快取，中斷後可續跑，不重抓已完成日期。
- 以官方上市／上櫃公司基本資料建立普通股清單，排除 ETF／ETN／DR／權證。
- 輸出前驗證日期、唯一鍵、OHLC 合理性與股票清單。
- TPEx 保留官方發布的次日參考價／漲停價／跌停價；TWSE 未發布於此來源的欄位留空，不自行推算。
- 產生 `manifest.json` 記錄資料範圍、筆數、股票數與來源。
- 可用 `--publish-dir` 將三個完成檔複製到已掛載／同步的 Google Drive 目錄。

## 2026-09-15 恢復方式修正

- TWSE 網站使用條款禁止未經同意以自動程式下載網站資料，因此不再用
  `MI_INDEX` 網站後端重建六年歷史資料。
- 已完整保留的 TPEx 原始快取繼續使用，不再向 TPEx 發送歷史請求。
- 缺少的 TWSE OHLC 改由 FinMind 文件化的 `TaiwanStockPrice` 個股區間 API
  恢復；僅供個人研究，不重新散布原始資料，並在 manifest 標示來源。
- `src/restore_market_data.py` 固定單線、每檔一次、逐檔快取；任何 4xx、配額
  或權限錯誤立即停止，只對暫時性網路／5xx 錯誤做有限次退避重試。
- 舊流程遭遇 307 時採「主輪不當成功、第二輪低速補洞」。此做法可解決資料
  完整性，但不改變 TWSE 網站條款，因此只保留為歷史紀錄，不再照抄執行。
